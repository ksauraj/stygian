## What you're looking at

This site is **not** a hand-made homepage. It is a folder of plain markdown
files - nothing but prose, headings, code fences and tables - rendered by the
theme. Browse the sidebar to see how it behaves:

- **`Getting started`** - install the theme and publish your first docs.
- **`Configuration`** - the `stygian:` config block and page front matter.
- **`Navigation`** - ordering, parent/child nesting and prev/next links.
- **`Customization ->`** - a nested section: theming and effects.
- **`Markdown elements`** - a torture test for the prose renderer: code,
  tables, callouts, Mermaid and friends.

Try the sun/moon button in the header: the theme switch ripples binary
glyphs across the screen from the point you click.
