This section is for people who build *with* the theme rather than just
writing pages: the design-token system, the extension hooks, the effect
suite, the automatic SEO module, a step-by-step migration guide from
just-the-docs, and the contribution workflow.

If you are evaluating a switch from just-the-docs, read
[Migration from just-the-docs](migration-from-just-the-docs) first: the
config surface is deliberately compatible.
